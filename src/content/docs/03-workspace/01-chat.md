The chat is where you work with the agent. Everything it does shows up as native UI: thinking, to-dos, tool cards, diffs and questions.

## Step by step

:::steps
### Send a message

Type, attach images or files, or tap the mic to dictate.

![Chat](/screens/chat_agent_working.webp "phone")

### Answer approvals

When the agent wants to run a command or edit a file, approve it right in the chat.

### Switch on the fly

Change model, effort, thinking and permission mode during a chat.

:::

## Good to know

- Edit or regenerate a message, fork, rename, share, export and delete chats.
- **Global context** tells every chat about your own standing instructions.
- Custom slash commands expand into full prompts.
