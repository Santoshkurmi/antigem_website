The code editor is built for touch, with Git built in.

## Step by step

:::steps
### Open a project

Pick a folder from the file explorer, or clone a repository.

![Editor and Git](/screens/code_editor.webp "phone")

### Edit

Tabs, line numbers, find and replace, undo and redo, and auto-indent.

### Commit and push

The source control view shows status and diffs; commit, pull and push from there.

:::

## Good to know

- Sign in to GitHub from **Settings → GitHub** to browse your repositories.
