AntiGem includes a full Termux-based Linux environment. No root and no proot.

## Step by step

:::steps
### Open the terminal

From the side bar, or from the editor's terminal sheet.

![Terminal](/screens/terminal_fastfetch.webp "phone")

### Install packages

Use `pkg install` or `apt install`, for example `pkg install python nodejs git`.

### Keep things running

The background service keeps long builds, servers and scripts alive.

:::

## Good to know

- Several sessions, themes, font sizes, quick keys and text selection.
- **ADB Connect** links the terminal's `adb` to the same phone over Wireless debugging.
