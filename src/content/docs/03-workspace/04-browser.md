The in-app browser previews the local dev servers you and the agent start, and the Browser MCP lets the agent use it too.

## Step by step

:::steps
### Start a server

Run your app in the terminal, for example `python -m http.server 8080`.

![Browser](/screens/browser_live_preview.webp "phone")

### Open it

Type `localhost:8080` in the browser.

### Inspect

Open Eruda DevTools for the console, network and DOM.

:::

## Good to know

- Desktop and mobile modes.
- A steady browser identity keeps Google sign-in working.
