AntiGem has a light theme and a dark theme in use at any time, and a mode that picks between them. Choose from 25 built-in themes, or have an agent make one for you.

**Where:** ☰ → **Settings** → **Themes**. Faster: ☰ → the **Themes** button (palette icon, next to **Settings**) opens a small theme panel over the app.

## Mode

### Color Theme

**Default:** **Dark**.

- **Auto (System)**: follows your phone. Light when the phone is light, dark when it's dark.
- **Light**: always the light theme.
- **Dark**: always the dark theme.

## Picking themes

Below the mode, the gallery has two lists:

- **Light theme**: used in Light mode, and by Auto when the system is light.
- **Dark theme**: used in Dark mode, and by Auto when the system is dark.

Tap a theme to use it; the one in use has a check mark (**In use**), and the default has a star. If you tap a dark theme while the mode is **Light** (or the other way round), the mode switches to match. The first themes in each list are the recommended ones, and the first is the default.

In the quick theme panel from the drawer, tap a theme to try it: the app changes behind the panel. Tap outside or **Close** when you're happy.

> On an OLED screen, **Midnight** (pure black) saves the most battery. For bright sunlight, try **High Contrast**.

## Make your own theme

Themes you make show up in the gallery with the others, marked **Custom**.

1. Add the **Theme** preset to an agent's MCP servers (for example **Settings → Claude Code → MCP servers**, or **Settings → Antigravity → MCP Servers**). See [Built-in MCP servers](../04-tools-and-extensions/02-built-in-mcp-servers.md#theme).
2. Start a new chat and ask, for example: "create a neon cyberpunk dark theme and apply it".
3. The agent creates it, checks the colors are readable, and applies it. Ask for changes ("make the accent less bright").

Jarvis can switch themes by voice too. See the step-by-step guide: [Make your own theme](../07-guides/09-make-a-theme.md).

### Delete a custom theme

Tap the trash icon (**Delete**) on the custom theme's card in the gallery, then confirm. If it's in use, the default theme takes its place. Built-in themes can't be deleted or changed (ask the agent to duplicate one first, then change the copy).
