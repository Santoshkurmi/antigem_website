**Settings → Android Development** sets up everything to build Kotlin / Jetpack Compose, Flutter and React Native apps on the phone itself.

## Step by step

:::steps
### Pick a framework

Install only what you need.

### Run a test build

Make sure everything works.

### Let the agent build

Ask the agent to build and install your app.

:::

## Good to know

- Builds target arm64 phones. For other CPU types, build on a PC.
