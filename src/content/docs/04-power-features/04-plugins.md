Plugins are small packages with a `manifest.json` and a JavaScript worker that add MCP tools, and can include Markdown skills.

## Step by step

:::steps
### Get a plugin

Install it from a ZIP, or from a plugin repository on GitHub.

### Turn it on

Enable, disable, reload and update plugins without restarting the app.

### Build your own

Read the [Plugin SDK](https://github.com/santoshkurmi/antigem/tree/standalone/extension_docs), or ask an agent with the Plugin Developer MCP.

:::

## Good to know

- Plugins run in an extension host that implements much of the Chrome extension API.
