REA lets any agent unpack and decompile APKs, and dig into Flutter, React Native and native libraries.

## Step by step

:::steps
### Install REA

Open **Settings → REA**. It installs in an Ubuntu environment inside the app.

### Turn on the MCP

Enable the REA preset in **Settings → MCP Servers**.

### Pick a mode

**On demand** (recommended, keeps the context small) or **direct**.

:::
