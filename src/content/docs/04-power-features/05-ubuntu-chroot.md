On a rooted phone (Magisk, KernelSU or APatch), the agents and the terminal can run in a real Ubuntu with `apt`, `glibc` and `sudo`.

## Step by step

:::steps
### Install the chroot APK

Use `AntiGem-v2.x.x-chroot.apk` from the releases page.

### Set it up

Pick official Ubuntu 24.04, 26.04 or 22.04, AntiGem's prebuilt image, a URL or a file.

### Switch to it

Open **Settings → Where agents run** and choose **Ubuntu chroot**.

:::
