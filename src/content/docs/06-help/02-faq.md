Quick answers to the questions people ask most.

:::details Is AntiGem free?
Yes. AntiGem is free and open source under the GPLv3. Some agents need an account or API key from their provider.
:::

:::details Do I need root?
No. Root is only needed for the optional Ubuntu chroot.
:::

:::details Which Android versions work?
Android 7.0 and newer, on 64-bit ARM phones. There is also an x86_64 build.
:::

:::details Does it work offline?
The app, terminal and editor do. Agents need the internet, unless you use a local model.
:::
