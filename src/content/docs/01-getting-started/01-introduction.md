AntiGem is an AI coding workspace for Android. It runs four coding agents on your phone (**Antigravity**, **Claude Code**, **OpenCode** and **Codex**), next to a real Linux terminal, a code editor and a browser the agent can control.

![AntiGem's chat, with Claude Code at work](/screens/chat_agent_working.webp "phone")

## What you can do with it

- **Build things by asking.** Describe an app, a script or a fix. The agent writes the files, runs them and shows you the result.
- **Work like on a computer.** A Linux terminal with `apt`, Python, Node.js, Git and Go. No root, no proot.
- **Use the models you want.** Your Google, Claude or ChatGPT plan, 200+ providers through OpenCode, or local models.
- **Do it hands-free.** Jarvis, the voice assistant, can run the whole app by voice.
