You aren't tied to one company's models. OpenCode and Claude Code can both use other providers with your own keys, and their models show up in the same model picker.

## Step by step

:::steps
### Pick the agent

Use **OpenCode** for 200+ providers and OpenAI-compatible APIs, or **Claude Code** for Anthropic-compatible ones.

![Bring your own models](/screens/model_picker_usage.webp "phone")

### Add the provider

Pick a preset (OpenRouter, Kimi, DeepSeek, Z.ai) or type a base URL and key.

### Test and fetch models

Test the connection, then fetch the model list. For OpenRouter you can fetch only free models that can call tools.

:::

## Good to know

- Local models: run Ollama or LM Studio and add it as an OpenAI-compatible endpoint.
