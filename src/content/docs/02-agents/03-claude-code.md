Claude Code runs Anthropic's official `claude` CLI, one process per chat. The app talks to it over its stream-json protocol.

## Step by step

:::steps
### Install it

Open **Settings → Claude Code** and install or update the CLI.

![Claude Code](/screens/chat_agent_summary.webp "phone")

### Sign in

Use a Claude subscription or an Anthropic Console account. Or add a provider: OpenRouter, Kimi, DeepSeek, Z.ai (GLM) or any Anthropic-compatible API.

### Check your usage

The chat shows the prompt-cache timer, context use, your 5-hour and weekly limits, and tokens per reply.

:::

## Good to know

- Settings cover chat defaults, permission rules, the command sandbox, MCP servers, plugins, `CLAUDE.md` and memory.
