Antigravity runs Google's official `agy` CLI, installed with Google's own installer inside the app's Linux environment.

## Step by step

:::steps
### Sign in with Google

Open a chat with Antigravity and follow the sign-in prompt.

![Antigravity](/screens/model_picker_usage.webp "phone")

### Choose a model

The model picker shows live quota for each model.

### Set security rules

Use a security preset, or per-project rules for which commands run on their own and which files the agent can touch.

:::

## Good to know

- **Cloud agents** run Antigravity chats on a Google cloud machine instead of the phone.
- MCP servers, skills and Google plugins work too.
