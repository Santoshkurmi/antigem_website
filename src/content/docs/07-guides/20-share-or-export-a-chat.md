---
title: Share or export a chat
description: Send a chat to someone, or save it as a Markdown file or a standalone HTML page.
updated: 2.0.4-beta.2
---

Keep a record of a chat, show someone how you built something, or ask for help with a chat that went wrong.

:::steps
### Open the drawer

Tap **☰** (top left).

### Open the chat's menu

Find the chat in the list and tap the **⋮** button (**Options**) at the right end of its row.

### Choose how

- **Export Markdown (.md)**: the chat as a Markdown text file, readable anywhere, good for notes and GitHub.
- **Export Standalone HTML**: one web page that opens in any browser.
- **Share**: saves the chat as an `.antigem` file and opens Android's share menu. Someone with AntiGem can open it and read the chat.

Exports are saved in `Download/AntiGem/Exports` on your phone; a message at the bottom says where, with **Open**.
:::

See [Chat history, sharing and exporting](../03-using-the-app/03-chat-history.md) for the other menu items (**Pin to top**, **Fork Conversation**, **Rename**, **Archive**, **Copy Conversation ID**, **Delete Conversation**) and how to open a shared chat.

> [!WARNING]
> A chat can contain file contents, paths, command output and anything you pasted, like keys or passwords. Read it before you share it.

## Copy one message

To share only one answer, use the copy button under the message, or select its text. See [Chat](../03-using-the-app/02-chat.md).
